Everything in this tutorial runs on `maude-wasm`, the library this site demonstrates. It works in Node and the browser. The low-level API runs a batch of input through a fresh interpreter:

```ts
import { runMaude } from "maude-wasm";

const { stdout } = await runMaude("reduce in NAT : 1 + 2 .");
// stdout contains "result NzNat: 3"
```

The structured API wraps the commands you've seen in this tutorial — `reduce`, `rewrite`, `search`, `match`, `unify`, `get variants`, `modelCheck`, `parse`, `show` — and parses Maude's answers into data instead of text. These listings are *live*: Run executes exactly this call through the library and shows the object it actually returns.

In a browser you'll want Maude off the main thread; this site's worker setup (a typed request/response protocol around the `Maude` class, with cancellation via `worker.terminate()`) is in the demo source — `src/worker.ts` and `src/useMaude.ts`.

To go deeper into Maude itself: the *Maude Manual* and *All About Maude* book cover strategies, object-oriented modules, parameterized modules and views, and much more that fits in this build. Head to the Playground to experiment freely.
